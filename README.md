# Инструмент массовой отправки формы (Link Reclamation Submitter)

Небольшой веб-сервис на Python (FastAPI + Playwright) для автоматической построчной отправки целей в веб-форму `https://linkreclamatiogrwc.uk/`.

## Что внутри и почему выбрал такой подход

- **FastAPI + простой фронтенд без тяжелых фреймворков (`static/index.html`)** — поднимается мгновенно, в одном окне сразу и форма ввода, и таблица со статусами по каждой строке.
- **Построчная очередь** — форма принимает только одну цель за раз, поэтому список разбирается построчно (с очисткой пустых строк и пробелов) и отправляется последовательно. Каждая строка предварительно проверяется под выбранный `Submission Type` (`Domain`, `IP` или `URL`), чтобы не гонять браузер зря, если в одной из строк опечатка.
- **Проверка вложений** — файл проверяется и на клиенте, и на сервере: только `jpg, jpeg, png, pdf`, размер строго до `2 МБ` плюс сверка сигнатуры файла (magic bytes).
- **Повторная отправка ошибок** — состояние каждого пакета сохраняется в `data/batches.json`. Если какие-то строки упали (таймаут, ошибка валидации или сбой сети), их можно переотправить кнопкой «Отправить неудачные повторно» (или по одной строке), не дублируя уже успешно отправленные цели.
- **Модуль капчи (`captcha_provider.py`)** — вынесен в отдельный файл, куда прокидывается `CAPTCHA_API_KEY` из `.env`.

## Быстрый запуск

Перед запуском создайте файл `.env` по образцу `.env.example` и укажите свой ключ:

```bash
cp .env.example .env
```

### Вариант 1. Запуск одной командой через Docker

```bash
docker compose up --build
```

После старта веб-интерфейс доступен по адресу: `http://localhost:8000`

### Вариант 2. Локальный запуск через Python

```bash
pip install -r requirements.txt
playwright install chromium
python app.py
```

Откройте в браузере: `http://localhost:8000`

## Проверка очереди без реальной отправки (`DRY_RUN`)

Если нужно быстро проверить работу веб-интерфейса, прогресс-бара, выдачу кодов `CF-XXXXXXXX` и повторную отправку упавших строк локально, включите в `.env`:

```env
DRY_RUN=true
```

В этом режиме любая строка со словом `fail` или `error` имитирует ошибку отправки, чтобы можно было сразу протестировать кнопку повторной отправки неудачных строк.
